[Discarded] 小米手机欧版MIUI通用卡刷教程

Jan 12, 2022
·
Other

各种原因，把备用机 MI6 刷成欧版 MIUI，大致流程差不多，记录下方便后续查阅

大致步骤如下：

数据备份 -> 解锁 -> 刷入Recover -> 刷入ROM -> 跳过Google验证

数据备份

数据是无价的！数据是无价的！数据是无价的！

手机变砖无所谓，重要数据一定要备份，诸如：照片，聊天记录，文档等

备份数据可以直接使用小米官方的工具（功能很多自行研究）：小米手机助手

具体步骤：

一，打开 开发者模式

设置 -> 我的设备 -> 全部参数 -> MIUI 版本（一直点）

二，开启 USB 调试

设置 -> 更多设置 -> 开发者选项 -> USB 调试

三，下载 小米手机助手 并安装

http://zhushou.xiaomi.com/

四，手机 USB 连接电脑

使用小米手机助手备份/恢复重要数据

不得不吐槽下即使是官方的工具，依然有 bug

解锁

第二步坑就不少了，新手机限制 7 天能解锁！MI0LIteZoom 使用快一年，解锁依然有 7 天限制，各种方法绕不过。最后等了 10 多天才解锁成功，恶心的不行！

准备如下：

- 小米账号（已有解锁权限，并且是当前设备登录的账号）
 
- 小米解锁助手

具体步骤：

一，绑定账号和关闭服务

- 建议登出 Google 账号，不然后续可能跳不过 Google 验证
 
- 登录常用的 小米账号 （注意：和后续解锁工具中的登录的账号保持一直）
 
- 关闭查找设备功能

二，申请解锁权限

进入 http://www.miui.com/unlock/ 登录 小米账号 申请解锁

三，下载解锁助手

进入 https://en.miui.com/unlock/download_en.html 下载并安装

四，解锁

1. 打开小米解锁助手，并登录小米账号
 
2. 手机关机后，使手机进入 Fastboot 模式（同时按住 电源键 + 音量下）
 
3. 查看小米解锁工具是否读取到设备
 
4. 点解 解锁（unlock）按钮

解锁成功后，手机回重启 开机界面回出现 unlocked 标志

刷入 Recovery

终于进入正题了，准备如下：

- ADB SDK
 
- TWRP 镜像

具体步骤：

一，下载 ADB（Android Debug Bridge） SDK

打开 https://developer.android.google.cn/studio/releases/platform-tools 选择对应系统版本下载并解压
 
- 该工具能够在连接的安卓设备上运行命令

二，下载 TWRP

打开 https://androidfilehost.com/?a=show&w=files&flid=318170 （官方定制 TWRP，支持 OTA 更新），没有则使用 https://twrp.me/Devices/Xiaomi 下载对应手机型号的 img 文件
 
- 注意：每台手机都要一个别称，例如 MI6(sagit)，找到自己手机的别称

三，刷入 TWRP

将下载的 TWRP 镜像 移动到 adb.exe 等文件的同一目录下
手机进入到 Fastboot 模式（开机同时按住电源键和下音量键）
手机用 USB 数据线连接电脑
在 adb.exe 所在目录，按住 shift 并右键，点击在此处打开 Powershell 窗口 / 在此处打开 CMD 窗口

依次运行如下命令

fastboot.exe flash recovery twrp.img // twrp.img 需要替换成你下载的镜像文件的路径
 
fastboot.exe boot twrp.img // twrp.img 需要替换成你下载的镜像文件的路径

如果不生效，则依次执行

./fastboot.exe flash recovery twrp.img // twrp.img 需要替换成你下载的镜像文件的路径
 
./fastboot.exe boot twrp.img // twrp.img 需要替换成你下载的镜像文件的路径

刷入 ROM

重头戏，具体步骤：

一，下载 ROM

进入 https://xiaomi.eu/community/ 获取对应版本 ROM 并下载

二，双清

- 进入 Recovery （开机同时按住音量加 + 开机键）
 
- 点 Wipe ，勾选 system, cache, data 然后滑动进行清除

三，传入 ROM

- 在 Recovery 模式传入下载的 ROM 包
 
- 如果传输失败，则重新挂载（在 TWRP 工具主界面点 Mount 然后点 Enable MTP），重新连接电脑

四，Install

点击 Install ，刷机完成，重启

跳过 Google 验证

概率问题，不能对症下药，多尝试，有如下方法：

1. 开机不连 WiFi，长按关机键进入飞行模式
2. 拔出手机卡重启手机
3. xx 上网
4. 刷机前登出 Google 账号
5. ADB
 
// 在 Recovery 终端中操作
 
adb shell settings put secure user_setup_complete 1
adb shell settings put global device_provisioned 1
adb reboot
 
// 或者
 
./adb shell settings put secure user_setup_complete 1
./adb shell settings put global device_provisioned 1
./adb reboot
 
// 上面不行则
 
dd if=/dev/zero of=/dev/block/bootdevice/by-name/frp

方法 2 和方法 5 都成功过，方法 5 是刷机前没有登出 Google 账号
